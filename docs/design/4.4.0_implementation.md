# 4.4.0 — implementation (as-built)

*Living companion to `4.4.0_iog_pricing_and_reprice_design.md`. The design doc says what the
model **is**; this doc records what has actually **shipped**, delta by delta — files touched,
what it replaced, how it was validated, and anything deferred or worth watching. Append a row
per major delta. When a bug arises, start here: find the delta that owns the surface, check
its "notes / watch" line against the design section it claims to satisfy.*

Convention: every delta ships as a git-diff patch, is verified `git apply --check` on the
current tracked baseline, and keeps the **full test suite byte-identical on uncapped /
non-IOG** as the standing guard. Capped behaviour is validated on the 3h-cap Highgrove
fixture (built by `tests/fixture_capped.py`).

8. **Carbon house-remainder — RESOLVED (P4.22, the carbon twin of P4.15).** `_aggregate_insights` now sources the carbon EV/house split from the SYNTHETIC dispatch on IOG: the physical EV clamp is superseded (dropped from the breakdown), the house remainder nets the synthetic EV **grid** carbon (the behind-meter saving never crossed the grid, so it is not subtracted), non-EV sub-meters keep counting.
