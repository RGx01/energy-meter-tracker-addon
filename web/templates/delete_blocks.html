Permanently delete blocks for a date range from the live database. Use this to remove bad data — e.g. a period affected by a sensor fault or gap fill error. This cannot be undone. Always take a backup first.
Deletes whole blocks in the range — every meter together — so the house and its devices stay consistent. To remove or rebuild a single device's usage (with the house remainder re-derived automatically), use Device History instead — deleting one meter's blocks here would leave the house total reading low.
Delete all historical imported data
Removes every block created by a historical import (API or CSV) and everything derived from it — rate derivations, import checkpoints and gap records — returning your account to its live-only state so you can re-import cleanly. Your live / CAD / settled data is untouched. A backup is taken automatically first. Use this if an import went wrong and you don't have a backup to restore.
Deleted ranges
Ranges you delete stay deleted — the automatic supplier sync will not re-create them. To bring one back, re-import it: this fetches the range fresh from the supplier API and clears the deletion. Ranges older than the API's reach can't be recovered this way (they'll say so).
