This is a read-only diagnostic. It reads Home Assistant's long-term statistics for the sensors you choose and reports how far back they go, their cadence, any gaps, whether they're energy or power, and how timestamps behave across DST. It writes nothing and creates no blocks. Pick a sensor per device, run it, and share the report to help scope historical import.
Octopus API retention
Checks how far back your import and export consumption reach on the Octopus API — export usually goes back less far than import. This is a read-only boundary check (two tiny lookups per channel); it imports nothing. Needs the API to be connected.
